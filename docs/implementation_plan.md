# 実装計画: Zen Notes App

## 1. 概要
「静寂と集中」をテーマにしたミニマルなライティング・アプリケーション。

## 2. ターゲット・コンセプト
- コンセプト選定フェーズ（1: 静寂の書斎, 2: 思考の庭, 3: 光の記録帳）

## 3. マイルストーン
### フェーズ1: コアUI構築 (現在)
- ベースカラーとタイポグラフィの決定。
- 集中モード（ディストラクション・フリー）の基本ロジック実装。

### フェーズ2: エディタ機能
- Markdown対応のシンプルなテキスト編集機能。
- オートセーブ機能。

### フェーズ3: 演出・磨き
- 微細なアニメーション。
- セッション保存機能。
